## 任务书

你是一名资深 Minecraft 1.8.9 Forge 客户端 UI 工程师。你要在 **Hoptimization** 项目中实现一个**简洁、现代、克制、好用**的 ClickGUI。

### 0. 开工前

1. 依次阅读 `docs/agent必看/00_先读我.md`、`01_开发规范.md`、`02_美术规范.md`、`04_版本管理规范.md`、`PROGRESS.md`。**本任务书中的所有尺寸、颜色、动效都必须引用 `02_美术规范.md` 中的 token，不得自创数值。**
2. 本任务只做 UI 框架与模块系统骨架，**不实现任何真实功能**。为了让 GUI 有内容可看，创建若干**占位模块**（见 §9），它们只有设置项、没有逻辑。
3. 若仓库尚未初始化，先按 `04 §1` 初始化并推送；之后**每个交付步骤（§11）都是一次完整的 `04 §3` 流程**：独立分支 → 提交 → build → 合并 `main` → 打标签 → 推送。

### 1. 设计理念（理解后再动手）

整体是一个**居中浮动的深色窗口**：左侧是安静的导航栏，右侧是嵌入的内容面板。
它不应该像"外挂菜单"，而应该像 **macOS 系统设置 / Raycast / Linear** 的深色模式——信息密度适中、层次靠明度而不是描边、只有一个强调色、动效短促顺滑。
打开它的感觉应该是："干净、顺手、一眼就知道在哪改什么"。

**窗口**
- 尺寸 680×420，屏幕居中；可通过拖动侧边栏顶部品牌区移动，位置存入 `ui.json`；窗口超出屏幕时自动夹回。
- 背后游戏画面盖 `backdrop` 遮罩。

**侧边栏（宽 176，背景即 `surface0`，无独立底色）**
- 品牌区（高 56，内边距 16）：`Hoptimization`（`body` SemiBold，`textPrimary`）+ 下方版本号（`caption`，`textTertiary`）。不放 Logo 图，不放彩色。
- 搜索框：TextField，宽 = 侧边栏宽 − 2×12，左侧 `search` 图标，占位符"搜索模块"，右侧显示快捷键提示 `Ctrl F`（`caption`，`textTertiary`）。
- 分类列表：每项高 32，左右外边距 8，内边距 12，`radiusControl`；图标 16 + 间距 8 + 名称（`body`）。
  - 默认：图标与文字 `textSecondary`，无背景。
  - 悬停：背景 `surface2`，文字 `textPrimary`。
  - 选中：背景 `accentMuted`，图标 `accent`，文字 `textPrimary`，左侧 3×16 pill 指示条 `accent`。
  - 切换分类时，选中背景与指示条**从旧位置平滑滑动到新位置**（`normal`），不是瞬切。
  - 名称右侧可显示该分类已启用模块数（`caption`，`textTertiary`），为 0 时不显示。
- 底部区（贴底，上方 1px `border` 分隔线，左右缩进 12）：
  - 配置档切换：显示当前配置名 + `chevron-down`，点击弹出下拉（列出配置、"新建"、"复制当前"、"重命名"、"删除"）。本任务实现 UI 与 JSON 读写即可。
  - `设置` 项：样式同分类项，点击后内容面板显示"设置页"（§6）。

**内容面板**
- 头部（高 56，内边距 20）：左侧分类名（`title`）+ 下方"N 个模块"（`caption`，`textTertiary`）；右侧分段控件 `全部 | 已启用`。
- 列表区：内边距左右 20、底 20；卡片间距 6；可滚动。

### 3. 模块卡片

**收起态（高 52，`surface2`，`radiusCard`，内边距 12）**
- 左：模块名（`body`，`textPrimary`）；下一行描述（`caption`，`textSecondary`，单行，超长省略号）。
- 右（从右往左）：Switch；若已绑定按键，Switch 左侧 8 处显示按键胶囊（高 18，`surface3`，`caption`，`textSecondary`）。
- 有设置项的模块在描述行最右显示 14px `chevron-down`（`textTertiary`），展开时旋转为向上（`normal`）。
- 模块关闭时模块名用 `textSecondary`，开启时 `textPrimary`——让"开着的东西"自然更醒目，**不要**给开启的卡片加强调色背景或描边。

**交互**
- 左键点 Switch：切换开关。
- 左键点卡片其它区域：展开/收起设置（无设置项时则切换开关）。
- 右键点卡片：展开/收起。
- 中键点卡片：直接进入按键绑定等待态（按键胶囊位置变为"按下按键…"，边框 `accent`）。
- 悬停：背景 `surface3`（`fast`）。

**展开态**
- 卡片高度平滑展开（`normal`，高度插值 + 内容透明度 0→1），下方卡片同步下移，不得跳动。
- 头部与设置区之间 1px `border` 分隔线（左右缩进 12）。
- 设置行高 32（Slider 行高 40，含上方标签），左右内边距 12；标签 `bodyRegular` `textSecondary`，控件右对齐。
- 设置项顺序：按定义顺序；最后固定一行"快捷键"（KeybindSetting）。
- 依赖隐藏的设置（`visibleWhen`）出现/消失时也做高度动画。
- 同时允许多个卡片展开。

### 4. 控件

严格按照 `02_美术规范.md §10` 实现 Switch / Slider / Segmented / Dropdown / Keybind / Color / TextField / Tooltip。
- 所有控件做成 `ui/component/` 下的可复用组件，ClickGUI、设置页、将来的 HUD 编辑器共用。
- 组件统一接口建议：`render(mouseX, mouseY, delta)`、`mouseClicked`、`mouseReleased`、`mouseDragged`、`mouseScrolled`、`keyTyped`、`getHeight()`、`isHovered()`。坐标为逻辑像素。
- 弹出层（下拉、取色器）渲染在最顶层，点击外部关闭，Esc 关闭；同时只存在一个弹出层。

### 5. 搜索

- 侧边栏搜索框输入非空时，内容面板切换为**全局搜索结果**：跨分类匹配模块名、描述、设置项名（中英文 + 拼音首字母可选，不强求）。
- 结果按分类分组，每组上方 `overline` 小标题（`textTertiary`）。匹配到的文字片段用 `accent` 着色。
- 头部标题变为"搜索结果"，副标题"N 个匹配"。
- 无结果：面板居中显示 `search` 图标（32，`textTertiary`）+"没有找到相关模块"（`body`，`textSecondary`）。
- 快捷键：`Ctrl+F` 聚焦搜索；在没有输入框聚焦时直接打字也会进入搜索框；搜索框聚焦时 `Esc` 先清空，再按一次才关闭 GUI。

### 6. 设置页（侧边栏底部"设置"）

同样用卡片分组展示：
- **主题**：
  - 主题网格：每个主题一张缩略卡（宽 120×高 76，`radiusCard`），卡内用该主题自己的颜色画一个迷你窗口（侧边栏条 + 两条卡片 + 一个 accent 圆点），下方主题名。选中卡外圈 2px `accent` 环。内置 6 个在前，自定义主题在后，最后一张是"+ 新建主题"虚线卡。
  - 自定义主题卡右上角悬停出现 `…` 菜单：编辑 / 复制 / 重命名 / 导出到剪贴板 / 删除。
  - 一行按钮：`从剪贴板导入`、`打开主题文件夹`。
- **强调色**：圆形色块 20×20 横排（"跟随主题" + 8 个预设 + "自定义"），选中项外圈 2px `textPrimary` 环。
- **外观**：界面缩放（Dropdown：80% / 90% / 100% / 110% / 125%）、减少动效（Switch）。圆角、窗口不透明度、HUD 不透明度、阴影强度、背景模糊属于主题风格参数，在主题编辑器里改。
- **ClickGUI**：打开按键（Keybind，默认 `RSHIFT`）。
- **HUD**：按钮"编辑 HUD 布局"（本任务只放按钮，点击后关闭 GUI 并 `LOGGER.info` 占位）。
- **关于**：版本号、"打开配置文件夹"按钮。

切换主题或强调色时整个 UI 实时平滑过渡（`normal`）。

### 6.1 主题编辑器

点击"新建主题"或"编辑"后，内容面板切换为编辑器（头部左侧返回箭头 + 主题名可直接编辑；右侧 `取消` / `保存` 按钮，`保存` 用 accent 实心按钮——这是全 GUI 唯一的实心强调按钮）。

- 左栏（约 55%）：可滚动的 token 列表，按 `表面 / 文本 / 强调 / 语义 / 效果 / 风格参数` 分组（`overline` 标题）。颜色行 = token 中文名 + 英文 token 名（`caption textTertiary`）+ 右侧色块与 HEX 文本，点击弹出取色器（含 alpha）。风格参数用 Slider / Switch。派生 token 默认显示"自动"，点击可改为手动覆盖，旁边有"恢复自动"。
- 右栏（约 45%）：实时预览，使用**正在编辑的**主题渲染一个迷你 ClickGUI（侧边栏 3 项、2 张卡片其中一张展开，含 Switch / Slider / Segmented），外加一个 HUD 卡片样例。预览不可交互。
- 模式切换 `深色 | 浅色`（Segmented），影响派生 token 算法。
- 对比度不足时，该颜色行右侧显示 `warning` 色小圆点 + Tooltip 说明（规则见 `02 §2.5`）。
- 未保存离开时弹出确认（弹出层：放弃 / 继续编辑）。
- 编辑器中的改动只作用于预览，保存后才应用到全局。

### 7. 滚动与裁剪

- 列表使用 `glScissor` 裁剪到内容区（注意 uiScale 与 MC 窗口坐标翻转）。
- 平滑滚动：滚轮设定目标值，当前值每帧向目标插值（时间常数约 80ms），到边界时夹紧，**不做橡皮筋回弹**。
- 滚动条：宽 3，pill，`textTertiary` @ 50%，贴右侧内边距 6；仅在滚动中或鼠标悬停列表区时显示，静止 800ms 后淡出。内容不足一屏时不显示。
- 列表上下边缘 12px 渐隐遮罩（内容向 `surface1` 渐变），提示"还有内容"；在顶/底时对应遮罩隐藏。

### 8. 打开 / 关闭

- 默认按键 `Right Shift` 打开；Esc 或再按一次打开键关闭（有输入框聚焦或在绑定按键时除外）。
- 打开动画：`slow`，窗口 scale 0.96→1.0 + alpha 0→1，遮罩 alpha 0→45%。关闭为反向，时长 ×0.75，动画结束后才真正 `displayGuiScreen(null)`。
- `doesGuiPauseGame()` 返回 `false`。
- 记住上次打开的分类与各分类滚动位置（会话内），分类写入 `ui.json`。
- 关闭时保存配置（遵守 `01 §7` 的写盘规则）。

### 10. 技术实现要求

- **渲染基础设施**（`ui/render/`）：
  - `RoundedRectShader`：GLSL 120 SDF 圆角矩形，支持填充色、四角独立半径、1px 边框、柔和阴影（模糊半径参数）。
  - 回退实现：三角扇 + 边缘羽化，shader 不可用时自动切换，只 warn 一次。
  - `Scissor` 栈：支持嵌套裁剪。
  - 所有 GL 状态改动必须还原（`01 §8`）。
- **字体**（`ui/font/`）：按 `02 §3` 实现 TTF 图集渲染器，支持多字号/字重缓存、中文按需加载、`getWidth` 缓存、省略号截断、颜色带 alpha。
- **动画**（`ui/anim/`）：`Animation(from,to,durationToken,easing)`，基于 `System.nanoTime()`，支持中途改目标；`ColorAnimation` 做 ARGB 分通道插值。全局"减少动效"开关生效。
- **主题**（`ui/theme/`）：按 `02 §2.7` 实现 `ThemeData` + `ThemeManager`；6 个内置主题全部实现；主题 JSON 读写、导入导出、缺失补齐；主题与强调色切换的全局插值动画。
- **缩放**：按 `02 §8` 计算 uiScale，Screen 内统一 `glScale`，鼠标坐标反算；窗口尺寸变化时重算。
- **性能**：GUI 打开状态下热路径零分配；卡片列表只渲染可视范围内的项。
- 禁止使用原版 `GuiButton` / `GuiTextField` / `drawRect` 渲染任何可见元素。
