# 00 · 先读我（所有 AI / 开发者开工前必读）

> 本目录是 **Hoptimization** 项目的最高规范。代码与规范冲突时，**以规范为准**；你认为规范有问题，先在汇报里提出，**不得擅自绕过**。

## 项目一句话

Minecraft **1.8.9 Forge（11.15.1.2318）纯客户端** 战斗优化模组。功能范围由项目所有者决定，不设限制。

## AI 工作流程（强制）

1. **先读**：`00` → `01` → `02` →（如涉及 UI）`03` → `04` → `PROGRESS.md`。然后按 `04 §3` 从最新 `main` 切出任务分支。
2. **只做被分配的任务**。不顺手"优化"无关代码，不新增未要求的功能。
3. **小步提交**：每完成一个可编译、可运行的最小单元就验证并 `git commit`。
4. **验证门槛**：交付前必须 `.\gradlew.bat build` 通过；涉及游戏内表现的必须 `.\gradlew.bat launchClient`（Gradle 8.8 下 `runClient` 因 Loom `0.10.0.5` `AbstractRunTask.getMain()` 校验限制已禁用并由 `launchClient` 替代）实测。没跑过就说没跑过，**禁止谎报"已测试"**。
5. **收工前**：合并到 `main`、打版本标签、推送 GitHub（`04 §3`），并在 `PROGRESS.md` 追加记录（含回退命令）。
6. 遇到规范没覆盖的情况：选最保守、最简单的方案，并在 `PROGRESS.md` 的"待决策"里记下来。

## 硬性红线（违反即返工）

- ❌ 不得修改 `build.gradle.kts`、`settings.gradle.kts`、`gradle.properties`、Forge/Mixin 版本，除非任务明确要求。
- ❌ 不得使用 `@Overwrite`（见 `01 §5`）。
- ❌ 不得在 `com.hoptimization.mixin` 包下放**非 Mixin 类**（该包被 `AutoDiscoveryMixinPlugin` 自动扫描，所有顶层类都会被当成 Mixin 加载）。
- ❌ 不得使用 Java 9+ 语法/API（`var`、`List.of`、`String.isBlank` 等）。目标是 **Java 8**。
- ❌ 不得在渲染/Tick 热路径里 `new` 临时对象、做反射、做 IO、打印日志。
- ❌ 不得 `git push --force`、不得改写已推送的历史、不得提交 Token/账号信息（见 `04 §6–7`）。
- ❌ UI 不得偏离 `02_美术规范.md` 的主题 token 体系，**禁止硬编码颜色魔法值**。
- ❌ 不得引入新的第三方依赖（需要的话写进"待决策"）。
