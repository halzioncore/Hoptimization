# 02 · 美术规范

## 1. 设计关键词

**简洁 · 现代 · 克制 · 好用**

- **克制**：一个界面只有一个强调色；装饰为零，层次靠明度差和留白，不靠描边和渐变。
- **安静**：默认状态低对比，交互状态（悬停/激活）才提亮。玩家打 PvP 时 UI 不能抢戏。
- **一致**：所有尺寸来自 4px 网格，所有颜色来自 token，所有动画来自同一套缓动。
- **可读**：字体清晰、对齐严格、信息分层（主文本 / 次文本 / 弱文本三级）。

参考气质：Linear、Raycast、Vercel Dashboard、macOS 系统设置。默认深色主题，同时提供浅色与多套配色主题（见 §2）。
**反面教材**：彩虹色、RGB 流光、粗描边、霓虹发光、大面积渐变、像素字体混搭圆角卡片、每个模块一个颜色。

## 2. 主题系统（多主题 + 完全可自定义）

### 2.1 原则

- 所有颜色都来自**当前主题**的 token。代码中**只能写 token 名**（`theme().surface2()`），不能写颜色值，也不能假设当前是深色或浅色主题。
- 主题 = **一套完整的 token 取值 + 若干风格参数**。内置主题只读；用户可以基于任意主题新建自定义主题，**每一个 token 都能改**。
- 切换主题时，所有 token 在 `normal` 时长内**平滑插值**过渡，不闪屏。
- 任何组件必须在**所有内置主题**下都好看、可读（交付前逐个主题截图自查）。

### 2.2 Token 清单（每个主题都必须给出全部基础 token）

**基础 token（主题文件里定义，可编辑）**

| Token | 用途 |
|---|---|
| `backdrop` | GUI 打开时覆盖游戏画面的遮罩（含 alpha） |
| `surface0` | 窗口最底层 / 侧边栏背景 |
| `surface1` | 内容区背景 |
| `surface2` | 卡片 / 模块行 |
| `surface3` | 卡片悬停、输入框、滑条轨道 |
| `surface4` | 按下、分段控件选中块、Tooltip |
| `border` | 唯一允许的描边：窗口外沿 1px、分隔线 |
| `borderStrong` | 输入框边框 |
| `textPrimary` | 标题、模块名、数值 |
| `textSecondary` | 描述、设置项标签 |
| `textTertiary` | 占位符、禁用、版本号、分组小标题 |
| `accent` | 开关开启、滑条已填充、选中指示条、聚焦环、搜索高亮 |
| `textOnAccent` | 强调色上的文字 / 开关开启时的拇指 |
| `thumb` | 滑条拇指、开关关闭时拇指以外的白色元素 |
| `success` `warning` `danger` | 语义状态，仅用于提示（保存失败、按键冲突等），不作装饰 |
| `shadow` | 窗口与弹出层阴影颜色（含 alpha） |

**派生 token（由代码自动计算，不存储，但自定义主题可选择覆盖）**

| Token | 默认算法 |
|---|---|
| `accentHover` | 深色主题：accent 混合 15% 白；浅色主题：accent 混合 10% 黑 |
| `accentMuted` | accent @ 14%（浅色主题 10%） |
| `hudBackground` | surface0 @ 风格参数 `hudOpacity` |
| `scrollbar` | textTertiary @ 50% |

主题必须声明 `"mode": "dark" | "light"`，派生算法据此选择。

**风格参数（每个主题自带，可编辑）**

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `radiusScale` | 1.0 | 0 – 1.5 | 所有圆角 token 乘此系数；0 = 直角风格 |
| `windowOpacity` | 1.0 | 0.80 – 1.0 | 窗口整体不透明度（<1 时建议配合背景模糊） |
| `hudOpacity` | 0.70 | 0 – 1.0 | HUD 卡片背景不透明度 |
| `shadowStrength` | 1.0 | 0 – 1.5 | 阴影 alpha 系数 |
| `blur` | false | — | 打开 GUI 时背景模糊 |

### 2.4 强调色

- 强调色**独立于主题可单独切换**：用户选了"午夜"主题仍可换成琥珀强调色。
- 预设 8 个：`#5B8CFF 蓝` `#7C8CFF 靛` `#8B7CFF 紫` `#2EC4A6 青` `#3DD68C 绿` `#F2A93B 琥珀` `#F2637E 玫红` `#E6E8EB 素白`，外加"自定义"（打开取色器）。
- 选"跟随主题"时使用主题自带的 accent。
- 选素白等浅色强调色时，`textOnAccent` 自动切为深色（按亮度对比自动判断，阈值相对亮度 0.5）。
- 强调色占屏面积 **≤ 5%**。一个界面只有一个强调色。

### 2.5 自定义主题

- **新建**：基于当前主题复制，命名后进入主题编辑器。修改内置主题时自动另存为"<主题名> 副本"。
- **主题编辑器**（详见 `03 §6`）：左侧按分组（表面 / 文本 / 强调 / 语义 / 效果 / 风格参数）列出全部 token，每项 = 色块 + HEX 输入 + alpha；右侧**实时预览**一张迷你 ClickGUI（侧边栏 + 两张卡片 + 开关/滑条/分段控件）。
- **对比度提示**：`textPrimary`、`textSecondary` 与 `surface1/surface2` 的对比度低于 WCAG 4.5 / 3.0 时，在该项旁显示 `warning` 色小提示——只提示，不阻止保存。
- **导入 / 导出**：一键复制主题 JSON 到剪贴板、从剪贴板导入；文件存放于 `config/hoptimization/themes/<id>.json`，放进去的文件下次打开自动识别。
- **容错**：导入的主题缺少某些 token 时用"石墨"对应值补齐；JSON 非法时提示失败，不崩溃。
- **删除 / 重命名 / 复制**：仅限自定义主题。

### 2.6 主题文件格式

```json
{
  "schema": 1,
  "id": "my_theme",
  "name": "我的主题",
  "mode": "dark",
  "colors": {
    "backdrop": "#000000B8",
    "surface0": "#0F1012",
    "surface1": "#16171A",
    "...": "所有基础 token，#RRGGBB 或 #RRGGBBAA",
    "accentMuted": "#5B8CFF24"
  },
  "style": {
    "radiusScale": 1.0,
    "windowOpacity": 1.0,
    "hudOpacity": 0.7,
    "shadowStrength": 1.0,
    "blur": false,
    "cardBorder": false
  }
}
```

- `colors` 中出现派生 token 即视为覆盖，否则自动计算。
- 颜色统一 `#RRGGBB` / `#RRGGBBAA`（注意：AA 在末尾）。
- `schema` 用于将来升级格式；读到更高版本时尽力读取并 warn。

### 2.7 代码结构要求

- `ui/theme/ThemeData`：不可变的 token 集合；`ThemeManager`：当前主题、切换动画（当前显示值 = 插值中的 `ThemeData`）、加载/保存/导入导出、内置主题注册。
- 组件每帧通过 `ThemeManager.current()` 取色，**不得缓存颜色到字段**（否则切换主题不生效）。
- 新增 token 必须同时：在本表登记、给所有内置主题赋值、在编辑器中可编辑。

## 3. 字体

- 自研 TTF 字体渲染（AWT 栅格化 → 字形图集纹理，带灰度抗锯齿），**不用原版像素字体渲染 UI**。
- 拉丁字母/数字：内置 **Inter**（SIL OFL），放在 `assets/hoptimization/font/`。
- 中文：运行时回退系统字体，顺序 `Microsoft YaHei UI` → `PingFang SC` → `Noto Sans CJK SC` → `SansSerif`。字形按需懒加载进图集。
- 数字使用等宽数字（Inter 的 `tnum` 不可用时，数值右对齐即可）。
- 字体按目标像素尺寸栅格化（乘以当前 UI 缩放 × 2 超采样），保证任何缩放下清晰。

### 字号阶梯（逻辑像素）

| Token | 大小 | 字重 | 用途 |
|---|---|---|---|
| `title` | 16 | SemiBold | 内容区页面标题 |
| `body` | 13 | Medium | 模块名、按钮 |
| `bodyRegular` | 13 | Regular | 设置项标签 |
| `caption` | 11 | Regular | 描述、数值单位、提示 |
| `overline` | 10 | SemiBold，字距 +0.6，全大写（英文） | 分组小标题 |

一个界面最多出现 **3 种字号**。

## 4. 间距与网格

- 基础单位 **4px**。允许值：`2 4 6 8 12 16 20 24 32`。不得出现 5、7、10、15 这类数。
- 容器内边距：窗口 `16`、卡片 `12`、控件 `8`。
- 列表项之间：`6`；分组之间：`20`。
- 对齐：所有文本左缘对齐到同一条网格线；数值、开关右缘对齐。

## 5. 圆角

| Token | 值 | 用途 |
|---|---|---|
| `radiusWindow` | 12 | 主窗口 |
| `radiusCard` | 8 | 模块卡片、弹出层 |
| `radiusControl` | 6 | 输入框、按钮、分段控件、侧边栏选中项 |
| `radiusPill` | 高度/2 | 开关、滑条轨道与拇指、标签 |

**嵌套规则**：内层圆角 = 外层圆角 − 间距（不小于 4），避免"肥圆角套瘦圆角"的错位感。
以上数值均再乘主题参数 `radiusScale`（pill 除外，始终为高度/2，`radiusScale = 0` 时也变直角）。
所有圆角必须**抗锯齿**（SDF shader 实现；回退方案用多段三角扇 + 边缘 1px 半透明羽化）。

## 6. 阴影与层级

- 只有两级浮层有阴影，颜色取 `shadow` token × `shadowStrength`：
  - 主窗口：偏移 y 16，模糊 48
  - 弹出层（下拉、取色器、提示）：偏移 y 8，模糊 24，alpha ×0.9
- 卡片**无阴影**，靠 `surface2` 与 `surface1` 的明度差区分。
- 背景模糊（原版 `shaders/post/blur.json`）由主题风格参数 `blur` 控制，内置主题默认**关闭**。

## 7. 动效

| Token | 时长 | 缓动 | 用途 |
|---|---|---|---|
| `fast` | 120ms | easeOutCubic | 悬停变色、开关拇指 |
| `normal` | 180ms | easeOutCubic | 展开/收起、选中指示条滑动 |
| `slow` | 240ms | easeOutQuint | 窗口打开（缩放 0.96→1 + 透明 0→1） |

- 关闭动画为打开的反向，时长 ×0.75。
- **禁止**：弹跳、回弹超调（overshoot）、旋转、闪烁、循环呼吸动画。
- 颜色变化必须插值，不得瞬切。
- 所有动画基于真实时间，可中途反向（从当前值继续，不跳回起点）。
- 设置中提供"减少动效"开关：开启后所有时长变为 0。

## 8. 缩放体系

- 自研 UI **不跟随** MC 的 GUI Scale。以逻辑像素设计，全局缩放系数：
  `uiScale = clamp(displayHeight / 1080 × 用户倍率, 0.75, 2.5)`（`UiScale.MIN_SCALE = 0.75`、`UiScale.MAX_SCALE = 2.5`），通用用户倍率默认 `1.0`，预设可选 `0.8 / 1.0 / 1.25 / 1.5 / 1.75 / 2.0`。
- **ClickGUI 独立缩放**：`ClickGuiScreen` 使用独立于 `uiScaleMultiplier` 的 `clickGuiScale`（范围 `0.75–2.0`，步长 `0.05`，默认 `1.25`），经 `UiScale.getClickGuiScale(clickGuiScale)` 计算缩放，并支持在界面内按住 `Ctrl + 鼠标滚轮` 实时微调（±0.05x）。
- 渲染时用 `glScale` 统一换算；鼠标坐标反向换算。

## 9. 图标

- 线性图标风格（参考 Lucide），1.5px 描边、圆头圆角，**单色白色 PNG**，渲染时按 token 着色。
- 尺寸：侧边栏 16、行内 14。
- 必需图标：`sword`（战斗）、`wind`（移动）、`eye`（视觉）、`layout`（UI）、`gauge`（性能）、`sliders`（杂项）、`search`、`settings`、`chevron-down`、`check`、`x`、`keyboard`、`move`（HUD 编辑）。
- 来源必须是开源许可（Lucide 为 ISC），在 `assets/.../icon/LICENSE` 注明。

## 10. 通用组件规格

| 组件 | 规格 |
|---|---|
| **开关 Switch** | 28×16，pill；关：轨道 `surface4`、拇指 `textSecondary`；开：轨道 `accent`、拇指 `textOnAccent`；拇指 12×12，左右内边距 2，位移动画 `fast` |
| **滑条 Slider** | 轨道高 4，pill，`surface3`；已填充 `accent`；拇指 12×12 `thumb` 色圆（浅色主题加 `border` 1px 描边），悬停/拖动时外圈 4px `accentMuted` 光晕；数值显示在标签行右侧（`textPrimary` + `caption` 单位）。按住 Shift 拖动为精细模式（步长/10）；双击数值可直接输入 |
| **分段控件 Segmented**（≤4 个选项的 Mode） | 高 24，底 `surface3`，`radiusControl`；选中块 `surface4` 平滑滑动；选中文字 `textPrimary`，未选 `textSecondary` |
| **下拉 Dropdown**（>4 个选项的 Mode） | 高 24，`surface3`，右侧 `chevron-down`；弹出层 `surface2` + 弹出阴影，选中项前有 `check` |
| **按键框 Keybind** | 高 22，最小宽 48，`surface3`，显示键名（如 `R`、`LSHIFT`）；等待输入时边框 `accent` + 文本"按下按键…"；Esc 取消，Backspace/Delete 清除 |
| **颜色 Color** | 左侧 16×16 圆角色块；点击弹出取色器：SV 方块 160×120 + 色相条 + 透明度条 + HEX 输入框 |
| **输入框 TextField** | 高 28，`surface3`，`radiusControl`；聚焦：1px `accent` 边框 + 光标闪烁 530ms |
| **提示 Tooltip** | 悬停 500ms 后出现，`surface4`，`caption`，最大宽 220 自动换行 |

**交互状态通则**：
- 悬停：背景提升一级 surface（如 `surface2 → surface3`），`fast` 过渡。
- 按下：再提升一级或亮度 −4%。
- 禁用 / 锁定：整体透明度 40%（置灰），不响应交互。需开启 `CheatMode` 的受限模块在未开启作弊模式时按 40% 置灰锁定展示，悬停提示锁定原因（`ui.hoptimization.cheat_locked`）。
- 鼠标指针命中区域 ≥ 视觉区域，小控件至少 20×20。

## 11. HUD 风格

- 与 ClickGUI 同一套语言、跟随当前主题：卡片背景 `hudBackground`、`radiusCard`、内边距 `6 8`、无阴影（`cardBorder` 为 true 时加 `border`）。
- 文本 `textPrimary`，标签 `textSecondary`，数值可用 `accent` 强调（每个 HUD 元素最多一处）。
- 默认贴边距屏幕 `8`，拖拽时吸附到边缘/中线/其它元素（吸附阈值 4，出现 1px `accent` 参考线）。
- 用户可选"纯文本模式"（无背景 + 1px 柔和阴影），兼顾老玩家习惯。

## 12. 文案

- 中文简短、动词开头或名词短语，不用感叹号、不用"超级""极致"等营销词。
- 模块描述一句话 ≤ 40 字，说清"它做什么"，不写实现。
- 中英文之间、中文与数字之间加半角空格：`延迟 50 ms`。
